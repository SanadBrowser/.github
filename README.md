## Open a useful report

Use [the issue chooser](https://github.com/SanadBrowser/.github/issues/new/choose) for community/documentation feedback. Browser defects belong in [the application issue tracker](https://github.com/muradaljohani/Sanad-Browser/issues). Security reports should be private; see [SECURITY.md](SECURITY.md).

The `.github/ISSUE_TEMPLATE` forms distinguish reproducible defects, ad-blocking/site-compatibility problems, feature proposals and accessibility/documentation feedback. They request evidence rather than personal browsing records.

## How these defaults work

GitHub can display these community files for organization repositories that do not define their own equivalent. A repository's own policy and templates take precedence. Licenses are repository-specific and do not inherit from this repository.
