نطوّر سَنَد الحرمين لتجربة تصفّح عربية واضحة، مع تبويبات معزولة، وتحكّم في الخصوصية، وتطوير مفتوح يمكن مراجعته. المشروع مستقل ويقوده [مراد الجهني](https://github.com/muradaljohani)، ونرحّب بالمساهمين في البرمجة والاختبار والتوثيق وإمكانية الوصول.

Sanad uses **Chromium through Electron**. We publish the application source, review changes through pull requests, and keep security boundaries and release limitations visible. Windows production distribution is through Microsoft Store.

## What we work on · مجالات التطوير

- **Browsing:** isolated tabs, reader mode, search within pages and local exports.
- **Privacy:** temporary private sessions, permission prompts and user-controlled filtering.
- **Compatibility:** reliable navigation and YouTube protection that preserves ordinary playback.
- **Quality:** repeatable Chromium tests, dependency review, secret scanning and installation checks.
