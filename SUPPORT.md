The hosted search page and the installed Windows browser are different surfaces. A website opened inside Chrome cannot provide the installed browser's filtering over unrelated Chrome tabs. Identify which surface you are using in a report.

## A useful report

Include the app, Chromium and Electron versions from About; operating system; installation source; steps; expected and actual result; and whether a fresh tab reproduces it. Crop screenshots to remove account names, unrelated tabs and personal data. Never attach a complete browser profile, cookie export or authentication-bearing URL.

For ad-blocking reports, distinguish an advertisement, a playback error, a service login/bot check and a consent prompt. An empty ad counter or synthetic fixture does not prove all live ads were blocked. Do not bypass browser security warnings or install a CI test certificate to troubleshoot.

## Updates and limits

Microsoft Store manages updates for Store installations. Source may be newer than the Store package; only the Store listing and installed version establish what is available to users. Development/CI artifacts are not a substitute for a signed production installer.

Support is maintainer-led and best effort; there is no service-level agreement or paid support program stated here. For sensitive project contact, the published maintainer address is **IM_MURAD7@hotmail.com**. This is not an invitation to send passwords or personal browsing records.
